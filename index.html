PeerAgent：让 Claude Code 和 Codex 互相审代码

在当前会话里请另一个模型检查代码，审阅意见直接带回来，不用切窗口、不用复制粘贴。用的是本机官方 CLI 和已有订阅登录，Python 标准库单文件，零 pip 依赖。

$curl -fsSL https://raw.githubusercontent.com/puck-muling/peer-agent/main/bootstrap.sh | bash
approved_auth

发请求前校验登录方式，防止静默切到按量扣费。

STOP

识别到风控特征就写入停机锁，阻断后续调用，避免连带封号。

read-only

审阅方只拿只读工具，不采信对方结论，要求证据在前。

peer freeze

用 SHA-256 固化已定方案，多轮之后不被悄悄推翻。
